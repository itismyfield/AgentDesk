# #8128 행 1 — 세션 관리와 진단

기준은 origin/main `cd9951d3cac6a4f0b81d02789facabbc6ed2a55d`다. 좌표와 비교는 기준 커밋의 소스에 근거한다. 첫 restart 조각 `ef2256904fd66c16aee9e13f1dd1295275c1a895`가 이 커밋의 조상이다. 실제 호스트 조합 수용은 #8120에서 확인한다. [기능 지도](user-feature-map.md)의 `reset-clear`, `effort-model`, `cancel-stop`, `threads`, `routines` 행과 연결한다.
