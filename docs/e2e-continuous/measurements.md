- 예약은 턴당 상한 × 3이다. 턴당 상한은 최근 이틀의 턴 최대값에 여유를 둔 값이다(Claude +22%, Codex +34%).
- 하루 12회는 배포 최대 9회(11-10~11-18의 하루 배포 4~9회)와 주기 재실행 2회, 재시도 1회다.
- 주기는 12시간(`core_interval_s=43200`)이다. 배포가 하루 여러 번 있어 주기 재실행은 배포가 없는 날을 덮는 용도다.
  12회를 모두 쓰면 하루 Claude 약 223만, Codex 약 102만 토큰이고 대부분 cache read다.
- 예산 토큰은 input+output+cache write만 센다(cache read 제외). 위 표의 '토큰 합'은 cache read를 포함한 네 항목 합계다.
- 배포 스모크도 같은 두 시나리오를 돌리므로 배포 한 번에 E-50·E-51이 두 번씩 돈다.
